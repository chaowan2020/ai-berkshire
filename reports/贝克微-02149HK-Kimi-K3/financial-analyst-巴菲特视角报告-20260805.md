### 1.2 巴菲特式解读

- **长期复合增长率依然漂亮**：收入 2021–2025 CAGR ≈ 28.7%（`calc`：(584.123/212.711)^(1/4)-1），净利 CAGR ≈ 21.0%。若只看五年曲线，这是一家高成长公司。
- **但边际趋势已经走平**：FY2025 收入 +0.9%，且增长引擎（分销渠道）被主动关停（-17.7%），新引擎（直销 +79.4%）体量尚小。巴菲特不在乎一年的停滞，但他在乎**停滞的原因是否可逆**——渠道手术是可逆的，需求疲软则不可逆；目前证据更偏向前者（合同负债从 4,014 万增至 8,784 万，直销客户扩张），但未经 2026 年数据验证。
- **报表净利 -26.8% 是会计现象**：5,270 万股份支付（其中研发费用口径 5,095 万）+1,425 万汇兑损失皆为一次性/非现金/非经常项。经调整净利 189.0（+18.5%）才是经营性真相（公司口径，本报告复核计算一致：122.0+52.7+14.2=189.0，高置信度）。
- **扣分点**：FY2025 经调整利润 +18.5% 的构成里，收入贡献仅 +0.9%，其余来自行政开支压缩（-13.6%）、研发现金开支收缩与税费为零——**利润增长的"含金量"低于表观增速**。

**本维度结论（2.5/5 星）**：五年高成长真实，但 2025 年失速且连续三个半年度平台化；利润质量靠调整项与费用压缩维持。成长股逻辑暂停，价值股逻辑登场。

### 2.2 巴菲特视角的四个判断

1. **ROE 连续五年 ≥15%（经调整口径），过关但趋势向下**。巴菲特的门槛是长期 ROE>15% 且不靠杠杆。贝克微几乎零杠杆（净现金），FY2022–FY2025 经调整 ROE 均在 15–27% 区间——**盈利能力本身是巴菲特会喜欢的**。但注意两个稀释因素：(a) IPO+配股募来的 6 亿多现金躺在账上吃 0.01–4.34% 利息，压低了 ROE 分母效率；(b) 若存货与预付的 9.34 亿继续膨胀，增量资本的回报率（ROIC 边际）将持续恶化。
2. **毛利率四连降（56.5%→51.7%）是必须直视的裂缝**。公司归因于存货跌价准备增加（FY2024 计提 857 万 → FY2025 计提 3,756 万）并称"剔除后无显著变化"（年报原文）。本报告核算：FY2025 若加回 3,756 万减值，毛利率约 58.2%（推算，中置信度）——反而高于 FY2024 剔除后水平。这意味着**真实售价体系尚未崩，但"卖不掉的库存"在吞噬报表毛利**。对巴菲特而言，这两种情形性质不同：前者是定价权丧失（致命），后者是库存管理失控（可修复但需证据）。
3. **口径警告（贯穿全篇）**：贝克微卖图案晶圆（不含封测），同行卖成品芯片。51.7% 的毛利率与圣邦（50.9%）、思瑞浦（46.6%）"接近"这件事本身，反而说明其**单位设计价值未必高于同行**——因为晶圆口径天然比成品口径高几个百分点（价值链位置差异，非定价权证据）。
4. **其他收益占比偏高**：FY2025 利息收入 1,447 万 + 政府补助 975 万 = 2,422 万，占税前利润 19.8%（推算，高置信度）。即**约两成"利润"来自资产负债表（IPO 余粮）和政府，而非经营**。巴菲特会问：剔除这些，核心经营利润（税前）= 131.0-12.6+52.7（加回 SBP）≈ 171.1 百万（推算，高置信度），对应核心经营利润率 29.3%——依然优秀，但要分清来源。

**本维度结论（3.5/5 星）**：经调整 ROE 16.5%、零杠杆、净利率 32%，盈利能力的"水平"达到巴菲特标准；"方向"（毛利率四连降、利润含两成非经营成分）扣分。核心问题不是赚不赚钱，而是赚的钱去了哪里（见现金流章）。

### 3.2 巴菲特式拆解：利润是真的，但现金被三样东西吃掉了

```
税前利润 122.0 + 非现金加回(SBP 52.7 + 存货减值 37.6 + 汇兑 14.2 + 折旧摊销 9.1)
= 营运资本变动前现金流 230.2        ← 盈利本身是"含现金"的
        │
        ├─ 存货再吞掉      -189.2   ← 第一黑洞：囤晶圆
        ├─ 预付供应商再吞掉  -70.8   ← 第二黑洞：锁产能
        ├─ 应付/合约负债回补  +38.0
        │
= 经营现金流仅 19.7
        ├─ Fablite 资本开支  -129.8  ← 第三黑洞：自建产能
        │
= 自由现金流 -110.1（连续第二年为负）
```

- **存货 4.67 亿（+48.1%），平均周转 506.6 天（`calc`）**，年末口径 604 天；其中原材料（未测试晶圆）4.24 亿（+118%）、产成品反而降至 0.43 亿（-65%）。公司解释为"基于客户需求与市场判断的备货"。巴菲特的读法：**一家收入零增长的公司把相当于年销售成本 1.66 倍的现金压在仓库里**，这不是营运资本，这是赌石。
- **预付供应商 4.67 亿**（供应商 A 2.64 亿 + 供应商 B 1.86 亿 + 其他），公司自认"多品种小批量→预留产能议价能力弱→高比例预付"（年报原文，高置信度）。截至 2026-03-25 仅 1.42 亿货物交付（年报披露）——**预付款回收周期以年计**。
- **有息负债的真实用途浮出水面**：FY2025 借款取得 2.47 亿、偿还 3.30 亿，借款全部为一年内到期无抵押流动资金贷款——**公司在用短债 + 配股款为存货和预付款融资**，而不是为扩张性资本开支融资。这是营运资本模式恶化的典型融资结构。
- **正面证据也必须记录**：贸易应收仅 5,239 万、DSO 32.7 天（`calc`）——下游回款极快，现金转换的问题**完全出在上游（预付）和仓库（存货），不在客户端**。这决定了问题的性质：是"模式性垫付"，不是"收入造假式挂账"。
- **FCF 连续两年为负**（FY2024 -2,692 万、FY2025 -1.10 亿）。按巴菲特"所有者收益"（Owner Earnings = 净利 + 折旧摊销 - 资本开支 - 必要营运资本增加）计算，FY2025 所有者收益约 **-1.4 亿**（推算：122.0+9.1-129.8-141.2 营运资本净增加，中置信度）——**账面赚 1.9 亿（经调整），股东真金白银的回报为负**。

**本维度结论（1/5 星）**：这是巴菲特框架下最致命的维度。利润与现金流的裂口连续两年存在且在扩大；模式从"轻资产 fabless"滑向"重营运资本 + Fablite"。1 星给 OCF 仍为正、应收极健康；若 2026 年中报 OCF 不能显著修复（渠道手术完成 + 存货出清），本维度应降至 0 分并触发卖出纪律。

### 4.2 巴菲特式解读

- **净现金 3.57 亿人民币 ≈ 市值的 22%**（357.1/1,605.2，`calc`），借款利率 2.43–3.60%、加权 2.82%，全部为无抵押信用贷款；未动用授信 14.73 亿。**无偿付风险，这是巴菲特喜欢的"能扛过任何坏年景"的资产负债表**。
- **但结构在变差**：(a) 现金中 4.03 亿为美元存款（占现金 73.7%，年报货币风险附注，高置信度），FY2025 人民币升值已造成 1,425 万汇兑损失且公司无对冲政策；(b) 已抵押存款 5,160 万是为开出 1.95 亿银行承兑汇票（应付票据）提供的保证金——即部分"现金"实际是供应链融资的抵押品；(c) 现金从 6.36 亿降到 5.47 亿，尽管年内有 1.07 亿配股流入——**配股的钱一年内就被营运资本和资本开支吞掉了**。
- **一个值得肯定的公司财务操作**：借款（2.82% 成本）与美元存款（收益率最高 4.34%）之间存在正利差，短期借款实质是套利 + 保流动性，而非生存性融资（推算，中置信度）。
- **资本承诺 4,980 万 + Fablite 设备预付款 1.64 亿（其他非流动资产）**：未来 12–24 个月资本开支将维持高位，净现金大概率继续下降。

**本维度结论（4/5 星）**：净现金、低杠杆、巨额未动用授信——安全垫厚实；扣分点为现金持续被营运资本/Fablite 消耗、美元敞口无对冲、抵押存款与票据循环。巴菲特会说：这是一张"能活下来"的表，但管理层在用它买越来越贵的存货。

### 7.3 安全边际判定

- **现价 28.00 vs 概率加权 3 年内在价值 48.43**：隐含约 **42% 折价**（28/48.43 ≈ 0.578），3 年年化回报约 +20%。
