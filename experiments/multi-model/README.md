# 多模型对比实验：同一家公司，不同 AI 各研究一遍

目标：用同一份 skill、同一家公司，在不同 Agent/模型上各跑一份研究报告，横向比较研究质量。

## 规则（就 4 条）

1. **同一 skill**：都用 `skills/investment-research.md`（轻量）或 `skills/investment-team.md`（完整团队），不要混用
2. **同一公司**：第一场对标实验固定用 **小米集团 1810.HK**（baseline 已存在）
3. **同一基准日附近**：数据截止日尽量接近，差太远没法比
4. **统一命名**：报告放 `reports/` 根目录，命名 `公司-研究类型-模型-推理级别-日期.md`

命名示例：

```
reports/小米集团-投资研究-kimi-k2-20260804.md        ← baseline（见下）
reports/小米集团-投资研究-claude-opus-high-20260805.md
reports/小米集团-投资研究-gpt5-medium-20260805.md
reports/小米集团-投资研究-claude-sonnet-low-20260805.md
```

> 现有 baseline：`reports/小米集团-投资研究-20260804.md`（Kimi 跑），改名归档或保留原名均可。

## 评分表（每份报告跑完填一行）

先跑 `python3 tools/report_audit.py extract/verdict` 拿到底线分，再人工填下表：

| 报告 | 模型 / 推理级别 | 审计准出? | 数据错误数 | 有非共识观点? | 估值区间 | 综合(1-5) |
|------|----------------|-----------|-----------|---------------|----------|-----------|
| 小米-kimi-k2 | Kimi / 默认 | ✅ 准出 | 0（1警告:PB口径） | 空方拥挤/轧空视角 | 15.8–84.8 | |
| | | | | | | |

**评分看什么**：
- 审计是否准出（底线，没过就淘汰）
- 关键数据（市值、收入、净利润）是否经得起 `financial_rigor.py` 验算
- 有没有超越市场共识的独立判断，还是"正确的废话"
- 结论是否明确（买入/观望/回避 + 具体价格区间），还是两头堵

## 产出

对比结论写进 `experiments/multi-model/RESULTS.md`（攒够 3 份以上报告再写）。
